# git-gui-open-error Specification

## Purpose

Определяет, что пользователь должен увидеть уведомление об ошибке вместо молчаливого бездействия, если при открытии диалога Git GUI не удалось получить статус репозитория.

## Requirements

### Requirement: Ошибка получения статуса репозитория показывается пользователю
Если при нажатии кнопки открытия Git GUI сервис не смог получить статус репозитория (путь до репозитория не заполнен в системной настройке, каталог не существует или не является git-репозиторием), система ДОЛЖНА (SHALL) показать пользователю уведомление об ошибке вместо того, чтобы никак не реагировать на нажатие.

#### Scenario: Путь до репозитория не заполнен
- **WHEN** пользователь нажимает кнопку открытия Git GUI, а системная настройка пути до репозитория пуста
- **THEN** диалог Git GUI не открывается и пользователю показывается уведомление об ошибке с подсказкой проверить настройку пути до репозитория

#### Scenario: Каталог не является git-репозиторием
- **WHEN** пользователь нажимает кнопку открытия Git GUI, а каталог, указанный в системной настройке пути до репозитория, не является git-репозиторием
- **THEN** диалог Git GUI не открывается и пользователю показывается уведомление об ошибке с подсказкой проверить настройку пути до репозитория

#### Scenario: Статус репозитория получен успешно
- **WHEN** пользователь нажимает кнопку открытия Git GUI и сервис успешно получил статус репозитория
- **THEN** диалог Git GUI открывается как прежде и уведомление об ошибке не показывается
