# git-gui-help-tour Specification

## Purpose

Определяет состав и порядок шагов интерактивного тура, запускаемого кнопкой "Помощь" в диалоге Git GUI, а также гарантию единственного активного экземпляра тура при повторных нажатиях и его корректное завершение при закрытии диалога.

## Requirements

### Requirement: Тур описывает все три кнопки над реестром в едином порядке
Тур ДОЛЖЕН (SHALL) содержать по одному шагу с описанием для каждой из трёх кнопок над реестром изменений (Pull, "выгрузить изменения в файловую систему", "Обновить реестр"), и эти три шага ДОЛЖНЫ (SHALL) идти подряд в порядке: "Обновить реестр" → "выгрузить изменения в файловую систему" → Pull.

#### Scenario: У кнопки "Обновить реестр" есть шаг тура
- **WHEN** пользователь дошёл в туре до кнопок над реестром изменений
- **THEN** тур показывает шаг с описанием кнопки "Обновить реестр"

#### Scenario: Три шага идут подряд в заданном порядке
- **WHEN** тур доходит до кнопок над реестром изменений
- **THEN** шаги показываются последовательно в порядке "Обновить реестр", "выгрузить изменения в файловую систему", Pull, без промежуточных шагов про другие элементы диалога

### Requirement: Повторное нажатие "Помощь" не создаёт второй активный тур
Пока тур уже активен, повторное нажатие кнопки "Помощь" ДОЛЖНО (SHALL) игнорироваться — новый экземпляр тура не создаётся и существующий тур не перезапускается.

#### Scenario: Повторное нажатие во время активного тура игнорируется
- **WHEN** тур уже открыт и пользователь снова нажимает кнопку "Помощь"
- **THEN** поверх текущего тура не появляется второй оверлей и текущий шаг тура не изменяется

### Requirement: Закрытие диалога завершает активный тур
Закрытие диалога Git GUI (кнопка "Закрыть") ДОЛЖНО (SHALL) удалять оверлей активного тура, если он был открыт, чтобы при повторном открытии диалога не оставался оверлей от предыдущего тура.

#### Scenario: Диалог закрыт во время активного тура
- **WHEN** пользователь закрывает диалог Git GUI, пока тур активен
- **THEN** оверлей тура удаляется вместе с диалогом

#### Scenario: Диалог открыт заново после закрытия во время тура
- **WHEN** диалог Git GUI открыт повторно после того, как был закрыт во время активного тура
- **THEN** оверлей предыдущего тура не отображается
