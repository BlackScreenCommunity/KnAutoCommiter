## Why

В интерактивном туре диалога Git GUI (кнопка "Помощь") у кнопки "Обновить реестр" нет шага описания, а шаг для Pull расположен в конце тура, оторванно от соседних кнопок. Повторное нажатие "Помощь" во время активного тура создаёт поверх него ещё один экземпляр тура с повторным затемнением экрана.

## What Changes

- Добавлен шаг тура для кнопки "Обновить реестр" (`refresh-button`) — сейчас отсутствует.
- Три шага тура для кнопок над реестром переставлены в существующей точке вставки в порядок: "Обновить реестр" → "Выгрузить изменения в файловую систему" → "Получить изменения с сервера Git". Остальной порядок шагов тура не меняется.
- В `onHelpButtonClick` добавлена проверка: если тур уже активен, повторное нажатие "Помощь" игнорируется — новый экземпляр тура не создаётся.
- Закрытие диалога (кнопка "Закрыть") во время активного тура удаляет его оверлей, чтобы при повторном открытии диалога не оставался "осиротевший" `.tour-layer`.
