## Purpose

Определяет, как кнопки "Pull", "выгрузить изменения в файловую систему" и "Обновить реестр" в диалоге Git GUI должны предъявляться пользователю: как визуально кликабельные текстовые кнопки с видимым стилем (рамка/заливка), расположенные компактно. Остальные кнопки Git GUI (шапка, "Закрыть", "Помощь", "Коммит", "Push") вне рамок этой capability.

## ADDED Requirements

### Requirement: Pull и "выгрузить в файловую систему" показывают только текстовую подпись
Кнопка Pull и кнопка "выгрузить изменения в файловую систему" в диалоге коммита ДОЛЖНЫ (SHALL) отображать только текстовую подпись, описывающую действие, без иконки.

#### Scenario: Pull показывает только текст
- **WHEN** диалог коммита отрисован
- **THEN** кнопка Pull отображает текстовую подпись "Получить изменения с сервера" (или эквивалентную) и не отображает иконку

#### Scenario: "Выгрузить в файловую систему" показывает только текст
- **WHEN** диалог коммита отрисован
- **THEN** кнопка выгрузки изменений в файловую систему отображает текстовую подпись, описывающую её действие, и не отображает иконку

#### Scenario: Обе кнопки продолжают работать по прежнему действию
- **WHEN** пользователь нажимает кнопку Pull или кнопку "выгрузить изменения в файловую систему" по её текстовой подписи
- **THEN** соответствующее действие (pull / выгрузка изменений в файловую систему) срабатывает точно так же, как и до добавления подписи

### Requirement: Pull, "выгрузить в файловую систему" и "Обновить реестр" визуально узнаваемы как кнопки
Кнопки Pull, "выгрузить изменения в файловую систему" и "Обновить реестр" ДОЛЖНЫ (SHALL) использовать видимый стиль кнопки (например, с рамкой или заливкой), а не прозрачный, похожий на ссылку вид.

#### Scenario: У каждой из трёх кнопок есть видимая граница
- **WHEN** диалог коммита отрисован в состоянии по умолчанию
- **THEN** кнопки Pull, "выгрузить в файловую систему" и "Обновить реестр" визуально отличимы от окружающего статичного текста рамкой, заливкой фона или эквивалентным видимым стилем кнопки

### Requirement: Pull, "выгрузить в файловую систему" и "Обновить реестр" расположены компактно
Эти три кнопки ДОЛЖНЫ (SHALL) быть сгруппированы и расположены компактно друг относительно друга, без лишних промежутков, и умещаться в существующей ширине диалога.

#### Scenario: Три кнопки не перекрываются и не обрезаны
- **WHEN** диалог коммита отрисован со всеми тремя кнопками в их итоговом текстовом виде
- **THEN** ни одна из трёх кнопок не обрезана и не перекрывает другую или соседний текст в строке
