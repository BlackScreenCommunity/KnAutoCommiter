## Why

Кнопки "Pull", "Выгрузить изменения в файловую систему" и "Обновить реестр" в диалоге коммита плохо считываются пользователем: у Pull и "выгрузки в ФС" была только иконка без подписи, а "Обновить реестр" выглядела как прозрачная ссылка, а не как кнопка. Пользователь не мог понять назначение иконочных кнопок без проб и ошибок. Изменение намеренно ограничено этими тремя кнопками; кнопка в шапке, "Закрыть", "Помощь", "Коммит" и "Push" пока не трогаем.

## What Changes

- Кнопка "Pull" (`GitGuiMessageBoxPullButton`): иконка убрана полностью, используется уже написанная (ранее закомментированная) подпись "Получить изменения с сервера" — только текст.
- Кнопка "выгрузить изменения в файловую систему" (`GitGuiDownloadChangesToFSButton`): иконка убрана полностью, добавлена текстовая подпись "Выгрузить в файловую систему" — только текст.
- Кнопка "Обновить реестр" (`GitGuiRefreshButton`): подпись у неё уже была, иконки не было и не добавляется — без изменений в этой части.
- Всем трём кнопкам добавлена видимая рамка/заливка через собственный CSS. `style` в коде остаётся `"transparent"` (платформенный `ButtonEnums.style.DEFAULT` пробовали — он даёт слишком крупную кнопку с обрезанной иконкой; после отказа от иконок эта проблема снята, но собственный CSS сохранён как более компактное и предсказуемое решение).
- Рамка/заливка реализована на контейнерах `<div>` из `getTpl()` (`{id}-refresh-button`, `{id}-reload-button`, `{id}-pull-button`), а не на внутренней разметке `BPMSoft.Button` — это оказалось надёжнее: рамка через ID внутреннего `-wrapperEl` кнопки отрисовывалась не для всех трёх кнопок одинаково.
- Строки локализации для подписей НЕ создаются автоматически: подписи заданы в коде как обычные значения `caption` (как и для остальных кнопок диалога), а фактическая регистрация локализуемых ресурсов в дизайнере BPMSoft — ручной шаг, выполняемый отдельно.
- Расположить эти три кнопки (в ряд "header-with-button" над реестром изменений) более компактно друг относительно друга, с учётом того, что Pull и Download стали шире после добавления подписи.
- **Кнопка в шапке (`GitGuiButton`), кнопки "Закрыть" (`CloseMessageBoxButton`), "Помощь" (`HelpButton`), "Коммит" и "Push" НЕ изменяются в рамках этого изменения** — по явному запросу оставить их пока как есть.
- Обновить селекторы интерактивного тура (`data-tour`) только если положение Refresh/Download/Pull внутри их текущего контейнера изменится в рамках компоновки; формулировки шагов тура не меняются.

**BREAKING**: отсутствует (изменение только во внутреннем UI трёх кнопок; публичные API, контракты сервисов и форматы данных не меняются).

## Capabilities

### New Capabilities
- `git-gui-buttons`: требования к текстовым подписям (без иконок), визуальному стилю и компактному расположению для кнопок Pull, "выгрузить в файловую систему" и "Обновить реестр" в диалоге Git GUI. Остальные кнопки Git GUI вне рамок этой capability.

### Modified Capabilities
(нет — в этом репозитории пока нет существующих спецификаций)

## Impact

- `Schemas/KnGitGuiMessageBox/KnGitGuiMessageBox.js` — `renderPullButton`, `renderDownloadChangesToFSButton`, `renderRefreshButton`; иконки и связанный с ними код (`imageConfig`, вспомогательная проверка наличия ресурса) убраны из этих трёх функций.
- `Schemas/KnGitGuiMessageBox/KnGitGuiMessageBox.less` — рамка/заливка/отступы на контейнерах `#KnGitGuiMessageBox-refresh-button` / `-reload-button` / `-pull-button`, компоновка строки `header-with-button`. Правила размера иконок (`#GitGuiDownloadChangesToFSButton-imageEl` / `#GitGuiMessageBoxPullButton-imageEl`) удалены — иконок больше нет.
- Ресурсы локализации `Resources/KnGitGuiMessageBox.ClientUnit/` — не редактируются в рамках этого изменения; регистрация строк выполняется вручную через дизайнер BPMSoft отдельно от реализации (изображения для этих трёх кнопок теперь не нужны вовсе).
- Не затрагиваются: `Schemas/MainHeaderSchema/*`, `getButtons()` (Close/Help), `renderCommitButton`, `renderPushButton`.
- Изменений на стороне сервера (`KnCommiterService`, `KnGitCliClient`, `KnIGitClient`) нет.
